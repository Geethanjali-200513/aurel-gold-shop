Design System

Use these colors:

Black: #0A0A0A

Dark background: #111111

Gold: #D4AF37

White: #FFFFFF

Muted text: #A3A3A3

Use gold mainly for buttons, borders, icons, hover states, and important highlights. Keep black as the dominant color.

Responsive Design

Make the website fully responsive for:

Desktop

Tablet

Mobile

On mobile, use a clean hamburger menu and 2-column product grid.

Important

The final website should feel like a premium men's fashion brand, not a generic template. Keep everything simple, spacious, sophisticated, and conversion-focused. Use high-quality men's fashion imagery and consistent black-and-gold branding throughout.
